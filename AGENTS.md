# Project Instructions

- Write internal developer instructions, code comments, prompts, and implementation notes in English.
- Communicate user-facing explanations in Russian.
- Keep the tarot engine deterministic when a seed is supplied and dependency-free unless a dependency is clearly necessary.
- Treat tarot output as symbolic reflection, not factual prediction or professional advice.
- Every discovered defect or behavior mismatch must receive a focused regression test. A fix is not complete until the test reproduces the old failure and passes with the correction.
